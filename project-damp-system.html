A three-person group project responding to a brief from the Building Research Establishment — designing a sensor-driven system to prevent condensation damp in homes. The brief required a working physical prototype that responded to real sensor data in real time.

I led the system ideation: ranking features, generating and selecting concepts, defining measurable requirements. I then built and tested the physical prototype using a DHT20 humidity sensor, PIR motion sensor, servo-actuated extractor fan, and Arduino with RGB LCD feedback. Red LCD indicates high humidity; green indicates safe conditions.

The critical evaluation honestly identified specific bugs and assessed the gap between controlled test performance and real-world deployment — a more useful outcome than a passing-grade summary would have been.
